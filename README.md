# VS Code Clone - File Explorer

A React-based code editor interface inspired by Visual Studio Code. This project provides an interactive file explorer where users can browse folders, open files, switch between tabs, and view file contents.

## 🚀 Features

- Interactive file and folder explorer.
- Recursive rendering of nested folders and files.
- Expand and collapse folders.
- Open files by clicking on them.
- Manage multiple opened file tabs.
- Switch between active tabs.
- Close opened file tabs.
- Display file icons based on file extensions.
- Syntax highlighting for code files.
- Resizable editor and sidebar panels.
- Welcome screen when no file is selected.

## 🛠️ Technologies Used

- **React.js** – Building reusable UI components.
- **TypeScript** – Type safety and better code organization.
- **Redux Toolkit** – Managing global application state.
- **React Redux** – Connecting React components with Redux.
- **Vite** – Development server and build tool.
- **Tailwind CSS** – Styling and responsive layouts.
- **React Icons** – Providing icons for files and folders.
- **Syntax Highlighting Library** – Displaying code with syntax highlighting.
